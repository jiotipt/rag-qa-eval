# OfficeCraft 办公技能集（示例知识库）

> 本目录是 **rag-qa-eval 配套的虚构示例知识库**，全部内容为原创、虚构，随仓库以 MIT 协议发布；
> 不对应任何真实公司、产品或人物。替换为你自己的文档后，请重新执行 `python build_index.py`。

## 技能清单

OfficeCraft 目前只覆盖**三类日常办公文档**的生成与整理：

| 技能 | 目录 | 解决的问题 |
|---|---|---|
| 会议纪要生成器 | `meeting-minutes-generator/` | 把会议记录整理为「决议-行动项-风险」三段式纪要 |
| 周报生成器 | `weekly-report-writer/` | 把一周素材组织为「本周完成-下周计划-风险求助」周报 |
| 汇报 PPT 大纲规划器 | `slide-outline-planner/` | 为工作汇报规划标准页数与每页要点的大纲 |

## 覆盖范围

- **范围内**：内部工作会议纪要、个人/团队周报、向上汇报的演示文稿大纲。
- **范围外**（技能集明确不支持，应拒答并引导找专用工具或专业人士）：
  - 短视频、动画、分镜脚本等视频制作类内容；
  - 代码编写与技术架构设计；
  - 医疗诊断、法律意见、投资/财务等专业建议；
  - 私人聚会、娱乐活动的策划文案。

## 文档约定

- 每个技能一个 `SKILL.cn.md`，包含：适用边界、工作流程、默认值、数字规则与篇幅限制。
- 测试集的 `ground_truth_context` 以 `kb_docs/<目录>/SKILL.cn.md#<章节标题>` 定位真值出处。
