# 汇报 PPT 大纲规划器 SKILL

## 适用边界

- 适用于企业内部的**工作汇报类**演示文稿：项目周报会、季度复盘、专项评审。
- 不适用：营销发布会风格的演示、产品广告页，以及视频/动画脚本——这些应使用品牌宣传或视频制作类专用工具。

## 页数结构

工作汇报大纲**默认 12 页**，固定分配如下：

| 页 | 内容 |
|---|---|
| 1 | 封面 |
| 2–3 | 背景与目标（2 页） |
| 4–8 | 进展与成果（5 页） |
| 9–10 | 风险与问题（2 页） |
| 11 | 下一步计划（1 页） |
| 12 | Q&A（1 页） |

## 篇幅规则

- 每页**不超过 6 行要点**；
- 每行**不超过 22 个汉字**，超出时拆行或拆页；
- 当汇报内容超过 **30 页**时，不允许继续扩页，必须**拆分为系列汇报**（例如「主汇报 + 专题附录」两场），每场各自遵守页数与行数规则。

## 风格与模板

- 默认模板为「**商务蓝**」：深色标题栏、单色强调、无装饰性插画。
- 默认只产出**文字大纲**（页标题 + 要点），不生成图片、不做排版成稿。

## 工作流程

1. 确认汇报类型、受众和时长（信息不足时先澄清）；
2. 按汇报类型选定页数骨架（默认 12 页）；
3. 为每页填写标题与要点；
4. 按行数/页数规则压缩；
5. 校对：页码连续、风险页与计划页不空、无超出范围的营销化表述。

## 与其他技能的关系

- 大纲中的进展素材可来自「周报生成器」的周报结论，但需要重新按页组织，不直接粘贴周报段落。
- 需要引用会议结论时，素材来源为「会议纪要生成器」的决议段。
